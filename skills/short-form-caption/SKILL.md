# Short-Form Caption Builder

Turn a video transcript or topic blurb into a tight, punchy short-form caption ready to copy-paste directly into Instagram, TikTok, or Reels.

## Output Shape & Invariants
```
Comment "<KEYWORD>" for <lead magnet / video / asset>

<Punchy opener line.>

<Problem line.>
<Setup line.>

<Turn / contrast.>

<Mechanism line — what the tool / system / fix does.>

<Outcome line.>
<Optional second outcome or kicker.>

#hashtag1
#hashtag2
#hashtag3
#hashtag4
#hashtag5
```

## Hard Constraints
1. **CTA on line 1**: Derived from transcript or configured fallback.
2. **Exactly 5 hashtags**: One per line.
3. **Hard ceiling of 500 characters**: Entire text including spaces, line breaks, and hashtags.
4. **Tone**: Punchy fragment rhythm, no corporate filler or generic AI intros.
